# Year 10 Biology Weekly Revision

Student site for the weekly MYP revision packs (recall missions plus one criterion per week).

- `index.html` – the student page
- `weeks.js` – the questions for each week (add new weeks here)
- `config.js` – paste the Apps Script web-app URL here
- `api.js`, `style.css` – supporting files

The teacher tracker is not part of this site. It opens from the Google Sheet
(menu: **Weekly revision › Open teacher tracker**).
